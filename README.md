# 🛡️ PhishGuard X

Advanced Threat Intelligence & Phishing Detection Chrome Extension


## Overview

PhishGuard X is a browser-based Threat Intelligence and Phishing Detection platform designed to help users identify malicious websites, phishing campaigns, and suspicious domains in real time.

The extension combines URL analysis, OSINT enrichment, reputation intelligence, and threat scoring to provide actionable security insights directly within the browser.

## Features

* URL Risk Analysis
* Phishing Detection
* Punycode Detection
* URL Shortener Detection
* HTTPS Validation
* VirusTotal Reputation Lookup
* Google Safe Browsing Integration
* ASN & Hosting Provider Intelligence
* Domain Age Analysis
* Screenshot Evidence Collection
* PDF Threat Reports

## Technology Stack
